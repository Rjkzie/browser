Quiet Browser 0.2.0: оптимизация производительности для Windows x64.

uBlock фильтрует через штатные callbacks Chromium без дополнительного межпроцессного вызова на каждый ресурс. Обновления состояния объединяются; вкладки сохраняют DOM-узлы. Блокировщик начинает подготовку в фоне после появления окна. Для быстрого ежедневного запуска добавлен ZIP: распаковать один раз и запускать внутренний `Quiet Browser.exe`. Portable `.exe` остаётся доступен, но распаковывает комплект при запуске.

Проверены фильтрация рекламы, поведение при аварии uBlock и отсутствие прямого fallback прокси. Полная холодная компиляция фильтров пока занимает несколько секунд. Сравнение с установленным Chrome на локальных страницах не является гарантией одинаковой скорости на любых сайтах.

Вкладки, свои поисковики, Perplexity/ChatGPT/DeepSeek/Qwen в боковой панели; uBlock Origin с адаптером Electron; встроенные Xray, userspace AmneziaWG/WireGuard и Tor; zapret с выбором стратегии и автозапуском. Ключи подключений вводятся пользователем и сохраняются через Windows DPAPI.

Сетевые ядра уже включены в файл. Встроенный VPN направляет через себя трафик браузера, без системного TUN. Для подключения нужен собственный сервер/ключ. Фирменные интерфейсы Happ/Amnezia не встроены. Поддерживаются отдельные ключи и конфигурации; HTTP-подписки, OpenVPN/IKEv2 и Amnezia Premium API пока не поддерживаются.

Проверены модульные тесты, реальная навигация Electron, sandbox, фильтрация рекламы uBO, разделение cookies и отсутствие прямого fallback при неработающем SOCKS; локальные тесты передачи данных через WireGuard и AmneziaWG. Доступность внешних VPN/Tor и zapret у конкретного провайдера не проверялась.

Tor здесь не заменяет Tor Browser. Cookies обычного режима сохраняются. Сайты и VPN-провайдеры могут собирать данные. zapret влияет на системный трафик и может запросить UAC. Сборка без цифровой подписи; полный security-аудит не проводился. Подробнее — README и список сторонних лицензий в репозитории.
