# Производительность 0.2.0

Замеры 16 октября 2026 года на одном компьютере Windows. Это воспроизводимые локальные сценарии, а не оценка скорости всего интернета.

## Запуск

Сравнивались два способа запуска **одной версии 0.2.0** на одинаковом отдельном тестовом профиле. Время измерялось от запуска процесса до загрузки домашнего интерфейса. Пользовательский профиль не открывался.

| Способ | Запуск 1 | Запуск 2 |
| --- | ---: | ---: |
| Portable EXE, повторная распаковка комплекта | 25,06 с | 26,44 с |
| Постоянный EXE из распакованной папки | 0,47 с | 0,67 с |

Первичное заполнение тестового профиля при отдельном подготовительном запуске заняло 3,26 с и не включено в две повторные пробы. Замер появления домашней страницы не включает подготовку uBlock и загрузку сайта. ZIP рекомендуется распаковать один раз и создать ярлык на внутренний `Quiet Browser.exe`. Portable оставлен для временного запуска.

Исходные данные: [startup-comparison.json](startup-comparison.json).

## Страницы и интерфейс

`npm run perf` создаёт локальную страницу со 160 небольшими JavaScript-ресурсами, загружает её пять раз и отдельно проверяет блокировку 160 запросов реальным правилом uBlock. Chrome запускается с отдельным временным профилем в headless-режиме; Quiet Browser использует скрытое окно Electron. Кэш включён в обоих вариантах. Это различающиеся оболочки и версии Chromium, поэтому результаты не следует распространять на все сайты.

| Метрика | До оптимизации | После |
| --- | ---: | ---: |
| Медиана пяти загрузок страницы | 46,66 мс | 47,00 мс |
| Изменения DOM списка вкладок за сценарий | 380 | 17 |
| Заблокированные запросы в тесте | 160 | 160 |
| Вызовы фонового JS из главного процесса за сценарий | не считались | 12 |

В последнем прогоне установленный Chrome 155.0.8059.80 показал медиану **42,69 мс**, Quiet Browser / Electron 44.8.0 / Chromium 152.0.7977.167 — **47,00 мс**. Ускорение обычной повторной загрузки относительно исходного браузера в этом тесте не установлено: разница находится в пределах вариации замеров. Подтверждены устранение перезапуска DOM вкладок при каждом изменении состояния и замена дополнительного межпроцессного вызова на каждый ресурс штатной фильтрацией расширения.

Полная холодная инициализация uBlock в новом профиле всё ещё занимает около **4,3 с**. Обычный запуск начинает её заранее в фоне. Адресная строка теперь принимает переход без ожидания компиляции, вкладку можно закрыть или создать новую; запросы страницы не отправляются до готовности защиты. Smoke-тест требует ответа адресной строки менее чем за 500 мс и проверяет отмену незавершённой вкладки.

Исходные данные: [performance-before.json](performance-before.json), [performance-after.json](performance-after.json).

## Проверки

- 14 модульных проверок URL, прокси, SHA-256 и импорта профилей.
- Smoke-тест реального собранного приложения: навигация, отзывчивость UI во время инициализации, отмена вкладки, sandbox, изоляция cookies, шифрование VPN-профилей, блокировка рекламы, отказ прокси без прямого fallback.
- Принудительное завершение фонового renderer uBlock блокирует последующий тестовый запрос; удаление слушателей `webRequest` сохраняет корректную идентичность callback.
- `QUIET_PERF_ASSERT=1 npm run perf`: менее 50 изменений DOM вкладок, менее 100 вызовов фонового JS со стороны главного процесса за ресурсный сценарий и медиана повторной загрузки менее 200 мс. Порог 200 мс — регрессия тестового сценария, не обещание скорости реальных сайтов.

Системные VPN/Tor-серверы, сеть пользователя и его история в замерах не использовались. Приватность не ослаблялась ради этих результатов.
